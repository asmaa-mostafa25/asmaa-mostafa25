## 🛠️ Featured Projects

### 🔐 CourseOnline.Auth — LMS Authentication Service
**What problem does this solve?**
A learning management system needs more than a login form — it needs identity you can trust across email, SMS, and sessions. This project is that trust layer.

**How I built it**
A backend authentication microservice handling registration, login, and multi-channel identity verification, with a split data-access layer — Dapper for optimized read queries, EF Core for schema management and migrations.

**Key engineering decisions**
Secured credentials with BCrypt hashing, enforced RBAC for permission control, and documented every endpoint with Swagger/OpenAPI to keep integration and testing straightforward.

**Technology:** ASP.NET Core 8 · C# 12 · SQL Server · EF Core · Dapper · JWT · OAuth 2.0 · Twilio · MailKit · Swagger
**Features:** Registration & login · Email/SMS verification · JWT-based session management · RBAC · Split read/write data access

🔗 [github.com/asmaa-mostafa25/CourseOnline-ASP.NET-Core](https://github.com/asmaa-mostafa25/CourseOnline-ASP.NET-Core)

### 🛒 E-Commerce MVC — Full-Stack Platform
**What problem does this solve?**
An online store isn't just a product list — it's a workflow: browsing, deciding, committing, paying. This project models that full path, end to end.

**How I built it**
An ASP.NET Core MVC application covering the complete purchase journey — storefront, shopping cart, checkout, and PayPal payment integration — plus an Admin/Customer RBAC system with a management dashboard for products, categories, and orders.

**Key engineering decisions**
Applied SOLID principles and the Repository Pattern with EF Core migrations to keep the architecture maintainable and testable as the platform grew.

**Technology:** ASP.NET Core MVC · C# · SQL Server · EF Core · Bootstrap 5 · jQuery · PayPal API
**Features:** Product catalog · Cart & checkout · Payment integration · Admin dashboard · Role-based access
