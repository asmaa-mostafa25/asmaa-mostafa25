## 🩸 Featured: BloodFlow — Smart Blood Inventory & Redistribution

> 🎓 Graduation project · I'm the **Team Leader** (9 members: backend, frontend, UI/UX, AI) and I own the **ASP.NET Core Web API**.

BloodFlow connects hospitals, blood banks, donors and recipients across Egypt's 27 governorates. It tracks blood stock per batch, handles normal and emergency requests, reserves units safely, and moves blood between organizations before it expires.

| | |
|---|---|
| 🏗️ **Architecture** | Four-layer Clean Architecture: Domain → Application → Infrastructure → Api |
| 🔐 **Security** | ASP.NET Core Identity + JWT, 5 roles, account lockout, staff approval workflow, audit log, active-account check on every request |
| 🧪 **Blood logic** | Batches, stock ledger, scheduled expiry job, FEFO (first-expiry-first-out) reservations, emergency requests |
| 🤖 **AI** | Integration with the team's AI service: demand forecast, shortage and expiry alerts |
| ✅ **Quality** | 40 xUnit tests, GitHub Actions CI (build, test, vulnerable-package check), RFC 9457 ProblemDetails errors |
| 📦 **Delivery** | Feature slices through reviewed pull requests — 5 slices done, donors next |

**Stack:** `.NET 10` `ASP.NET Core Web API` `EF Core 10` `SQL Server` `Identity` `JWT` `xUnit` `GitHub Actions`
